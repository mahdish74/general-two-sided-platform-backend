This is a Java Spring Boot backend designed for a general-purpose two-sided platform. It allows registration, authentication, and interaction between service requesters (e.g., customers) and providers (e.g., laundry workers).

## 🚀 Features

- JWT-based authentication and role-based access control
- Role support: `CUSTOMER`, `LAUNDRY_WORKER`, `DISPATCHER`, `SUPERVISOR`, `ADMIN`
- Endpoints for:
  - User registration and login
  - Laundry request creation and tracking
  - Job assignment and updates
- REST API with validation and comprehensive tests

---

## 🛠️ Tech Stack

- Java 21
- Spring Boot 3.4.5
- Spring Security
- Spring Web & JPA
- H2 / PostgreSQL (configurable)
- JUnit 5 & Mockito
- Maven
